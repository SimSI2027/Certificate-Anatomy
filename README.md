# Certificate Anatomy

Interactive motion-based exploration of a Certificate Signing Request and its issued certificate.

The project uses synthetic demonstration data and real synthetic cryptographic artifacts.

## Planned learning flow

1. Inspect the finished signed certificate.
2. Explode the certificate into understandable fields.
3. Trace the certificate back to the CSR.
4. Explode the CSR into its components.
5. Follow manual CSR submission to the Issuing CA.
6. Watch the Issuing CA create and sign a new certificate.
7. Return the certificate to the original requester.
8. Install it and associate it with the retained private key.

## Safety

- Synthetic identities and names only.
- No production certificates.
- No private keys committed.
- No PFX or P12 files committed.
